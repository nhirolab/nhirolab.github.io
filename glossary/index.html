用語集

AIとパソコンの言葉を、やさしく。

AI、パソコン、インターネットの言葉を、中学生にも分かる言葉で説明します。知りたい言葉は、下の検索ボックスで探せます。

基本の言葉

AI(エーアイ)/ 人工知能

人間のように「考えているように見える」コンピューターの技術です。

文章を読む、絵を描く、質問に答えるなど、人間がやる作業をまねします。本当に考えているわけではなく、たくさんのデータから学んだ「パターン」を使っています。

生成AI(せいせいエーアイ)

文章や絵、音楽など、新しいものを「作る」AIです。

ChatGPTやClaude、Geminiなどが代表です。「こんな絵を描いて」と頼むと、その場で作ってくれます。

たとえ:何でも描いてくれる、とても物知りなイラストレーター兼ライターです。

LLM(エルエルエム)/ 大規模言語モデル

文章を読み書きするのが得意なAIの「中身」です。

とても大量の文章を読んで学んだAIです。「次に来そうな言葉」を予想する力がとても高く、会話や文章づくりができます。ChatGPTやClaudeは、このLLMを使ったサービスです。

モデル

AIの「頭脳」にあたる部分です。

ニュースで「新しいモデルが出た」と言うときは、新しい頭脳ができたという意味です。GPT-6.1 SolやClaude Sonnet 5.5は、モデルの名前です。数字が大きいほど新しいことが多いです。

AIに頼むときの言葉

プロンプト

AIに出す「お願いの文章」です。

「夏休みの作文のアイデアを5つ出して」のように、AIに書いて伝える指示です。頼み方で答えの質が変わります。

チャットボット

文字で会話できるAIのことです。

ChatGPTやClaudeのように、チャットで話しかけると返事をしてくれます。

ハルシネーション

AIが、知らないことを知っているふりをして、もっともらしいウソを答えてしまうことです。「知ったかぶり」とも呼ばれます。

AIは、分からないときに「分かりません」と言わず、自信ありげに答えてしまうことがあります。人名、数字、本のタイトルなどは特に間違えやすいので、大事なことは自分で確認しましょう。

たとえ:テストで分からない問題に、それっぽい答えを書いてしまう感じです。

最近よく出てくる言葉

AIエージェント

頼まれた仕事を、自分で考えて進めるAIです。

ふつうのAIは「聞かれたら答える」だけです。エージェントは、調べる、アプリを使う、結果をまとめるなど、いくつもの作業を自分で続けます。第1回のOpenAIの「dots」もこの仲間です。

たとえ:質問に答えるだけの先生ではなく、頼んだ宿題を最後まで手伝ってくれる助手です。

マルチモーダル

文字だけでなく、画像や音声も扱えることです。

写真を見せて「これは何?」と聞いたり、声で話しかけたりできるAIのことです。

API(エーピーアイ)

ほかのアプリがAIを使うための「入り口」です。

会社やアプリの作り手が、自分のサービスにAIの機能を組み込むときに使います。料金は、使った量に応じてかかることが多いです。

仕組みの言葉

学習(がくしゅう)

AIが大量のデータを読んで、力をつけることです。

AIを作る段階の話です。たくさんの文章や画像を読み込んで、パターンを覚えます。

クラウド

インターネットの向こうにある、大きなコンピューターです。

自分のパソコンではなく、ネット上のコンピューターで仕事をする仕組みです。多くのAIはクラウドで動いています。

セキュリティ

コンピューターやデータを、悪い人から守ることです。

第1回のニュースのGemini 4 Argonのように、AIがパソコンの弱点を見つける力は、守る側にも攻める側にも使えます。そのため、AIの安全の話によく出てきます。

パソコンの基本

OS(オーエス)

パソコンやスマホを動かす、いちばん土台になるソフトです。

アプリを動かしたり、画面に文字を出したりする役目をします。パソコンではWindowsやmacOS、スマホではiOSやAndroidが有名です。

たとえ:アプリが「役者」なら、OSは舞台と進行役です。

アプリ

何かの目的に使うソフトのことです。

ブラウザ、メール、ゲーム、ChatGPTなど、ふだん使うものの多くがアプリです。正しくは「アプリケーション」といい、パソコンでは「ソフト」と呼ぶこともあります。

ブラウザ

インターネットのページを見るためのアプリです。

Chrome、Safari、Edgeなどが有名です。ページのアドレスを入れたり、言葉で検索したりして、見たいページを開きます。このサイトを見ているのも、ブラウザです。

ファイルとフォルダ

ファイルは「書類や写真そのもの」、フォルダは「それを入れる箱」です。

作文(ファイル)を「宿題」という箱(フォルダ)に入れて整理するイメージです。フォルダの中に、さらにフォルダを作ることもできます。

メモリとストレージ

メモリは「作業中の机」、ストレージは「しまっておく本棚」です。

メモリは、いま使っているデータを一時的に置く場所で、電源を切ると消えます。ストレージは、写真や書類をずっと保存しておく場所です。どちらも大きいと余裕が出ますが、役目はちがいます。

CPUとGPU

CPUはパソコンの「頭脳」、GPUは「絵や大量の計算が得意な助っ人」です。

CPUは、いろいろな仕事を順番に進める中心の部品です。GPUは、画像の処理や、たくさんの計算を同時にこなすのが得意です。AIの学習や動作でも、GPUが大活躍しています。

アップデート

ソフトを新しいバージョンにすることです。

新しい機能が増えるだけでなく、「弱点(悪い人に狙われる穴)」をふさぐ大事な役目があります。通知が出たら、早めに行うのがおすすめです。

バックアップ

大事なデータの「コピー」を、別の場所にとっておくことです。

パソコンがこわれたり、データが消えたりしても、コピーがあれば元にもどせます。外付けのディスクに入れる方法や、クラウドに保存する方法があります。

たとえ:大事な書類をコピーして、別の部屋にもしまっておく感じです。

スクリーンショット

いま見ている画面を、そのまま「写真」にして保存することです。

略して「スクショ」ともいいます。エラーの画面を見せたいときや、あとで見返したい情報を残したいときに便利です。やり方の例は、Windowsなら「Windowsキー + Shift + S」、Macなら「Shift + Command + 3(画面全体)」または「Shift + Command + 4(選んだ範囲)」、スマホは電源ボタンと音量ボタンを同時に押す機種が多いです。操作は、機種やバージョンで変わることがあります。ほかの人の個人情報やパスワードが写っていないか、気をつけましょう。

インターネットの基本

インターネット

世界中のコンピューターをつなぐ、大きなネットワークです。

ホームページを見る、メールを送る、動画を見る、AIに質問する。どれもインターネットでつながっているから、できることです。「ネット」と略して呼ぶことも多いです。

Wi-Fi(ワイファイ)

ケーブルなしで、インターネットにつなぐ電波の仕組みです。

Wi-Fiそのものがインターネットなのではなく、インターネットにつなぐための「無線の道」です。家や店のWi-Fiにつなぐと、スマホの通信量(ギガ)を使わずにネットが使えます。

IPアドレス(アイピーアドレス)

インターネットにつながっている機械の「住所のような番号」です。

「203.0.113.25」(見本の数字です)のような、数字のならびです。データを送る相手を見つけるために使われます。ページのURLの名前は、裏でIPアドレスという番号に置きかえられて、届け先が決まります。ふつうは、IPアドレスだけで、名前や家の住所まで分かることはありません。

URL(ユーアールエル)

インターネット上のページの「住所」です。

「https://nhirolab.github.io/」のような、文字のならびです。ブラウザの上の欄に入れると、そのページが開きます。リンクをクリックしたときも、URLのページが開いています。

サーバー

ネット上で、データやサービスを預かって届けてくれるコンピューターです。

ページを開くと、サーバーにお願いが届いて、サーバーがページのデータを送り返してくれます。AIも、多くはサーバーの上で動いています。

たとえ:注文を受けて、料理を出してくれるお店の人です。

Cookie(クッキー)

ウェブサイトが、あなたのブラウザに残しておく「小さなメモ」です。

ログインしたままにしたり、買い物かごの中身を覚えたりするのに使われます。便利な一方で、どのサイトを見たかを記録して、広告に使われることもあります。ブラウザの設定で、削除したり、制限したりできます。

たとえ:お店の人が、来てくれたお客さんの好みを、小さなメモに書いておく感じです。

検索エンジン

言葉を入れると、関係するページを探してくれるサービスです。

GoogleやBingなどが有名です。「AI 初心者」のようにキーワードを入れて探します。AIチャットは、答えを文章でまとめてくれる点が、検索とはちがいます。

SNS(エスエヌエス)

ネット上で、人とつながったり、写真や文章を見せ合ったりするサービスです。

X、Instagram、LINEなどが有名です。「ソーシャル・ネットワーキング・サービス」の略です。いちど投稿した写真や文章は、消したあとでも、ほかの人に保存されたり、広まったりすることがあります。個人情報や、いまいる場所が分かる情報には、気をつけましょう。

ダウンロードとアップロード

ダウンロードは「ネットから自分の機械へ」、アップロードは「自分の機械からネットへ」データを送ることです。

アプリを入れるのはダウンロード、写真をクラウドに保存するのはアップロードです。知らないサイトからのダウンロードには、気をつけましょう。

安全のための言葉

パスワード

自分だけが知っている、ログインのための「合い言葉」です。

長くて、ほかの人が思いつかない文字にします。同じパスワードを、いくつものサービスで使い回さないことが大切です。たくさんあって覚えきれないときは、パスワード管理アプリを使う方法もあります。

二段階認証(にだんかいにんしょう)

パスワードに加えて、もう一度「本人かどうか」を確かめる仕組みです。

パスワードのあとに、スマホに届く番号を入れたり、指紋や顔で確認したりします。パスワードがもれても、すぐには悪用されにくくなります。

フィッシング詐欺(さぎ)

本物そっくりのメールやサイトで、パスワードやカード番号をだまし取る手口です。

「アカウントが止まります」「荷物をお届けできません」などの連絡から、にせのサイトに案内されます。メールのリンクは押さずに、公式アプリや、自分で検索したページから開くと安全です。

ウイルス / マルウェア

パソコンやスマホに入りこんで、悪さをするプログラムです。

データをぬすんだり、こわしたり、勝手に使ったりします。あやしいファイルやリンクを開かない、アップデートをする、ウイルス対策ソフトを使うことで、危険を減らせます。ウイルスは、悪いプログラムの総称「マルウェア」の一種です。

HTTPS(エイチティーティーピーエス)

ネットの通信を暗号にして、のぞき見されにくくする仕組みです。

URLが「https://」で始まるページは、通信が暗号で守られています。ただし、「https=安全なサイト」とは限りません。にせサイトでも、httpsになっていることがあります。

個人情報(こじんじょうほう)

だれのことか分かってしまう、あなたの情報です。

名前、住所、電話番号、誕生日、メールアドレス、パスワード、カード番号などです。ネットやAIチャットに入力するときは、むやみに入れないようにしましょう。

見つかりませんでした。ひらがなやカタカナを変えて、もう一度探してみてください。

言葉の意味は、使う人や場面で少しずつ違うことがあります。ここでは、初心者向けに「だいたいこういう意味」という説明にしています。
